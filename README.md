# GSTAT-index-tool
This tool is being built so that proper documents can be collected, combined, and document bundle created that are uploaded on the GSTAT E-filing portal.

Right now, we have to use another Open source tool, [buntool](buntool.co.uk) and the present tool.

### Instructions
1. Open [buntool](buntool.co.uk) and start building a bundle.

2. Add the coverpage if you want.

3. In bundle title write "Index" and in case name write your case name, assessee vs sto

4. create the following section break:
    - Appeal memo
    - Affidavits
    - Order in Original
    - Show Cause notices
    - Order(s) in Appeal
    - Appeal Notices
    - First Appeal
    - Vakalatnama/Authorization
    - Annexures
    - High Court order
    - Payments
    - pre-deposit Challans 
    - Any Other documents

Change the section breaks as per your need, add or remove them.
5. Add documents against each sectioon, properly changing their name, so appeal grounds become grounds of appeal, appeal facts, etc, same for other documents like APL-04 or DRC-07 and OIO (Order in Original) and OIA (Order in Appeal). Upload all relevant documents against each section so one section can have multiple PDFs. 

6. open "advanced Settings" and change Date format to "none" and set printable mode to "off".

7. click on create bundle and once created, download bundle. This gives you a combined PDF with proper index, page numbering. You can upload this under "other documents" as "combined PDF".

8. Now upload this PDF to the tool here.

9. Then click on export all pdf.

10. You can click on "add index to appeal" so the index pdf is also made part of the appeal memo. 

11. Download all sections  and upload combined documents against each section as accepted by the GSTAT portal website and the combined one as well.
